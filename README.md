I'm a final-year Computer Science (DCIT) student at the University of Ghana, and the solo founder and developer of **SportCache** — a sports technology platform building data infrastructure for athletics and cycling events across Ghana and Africa. SportCache powers live results, broadcast overlays, and a public API for real meets, including the Accra Open Championship, Senior African Athletics Championship, and Cape Coast Open Championship, in partnership with SEED Afrique and Ghana Athletics.

Right now I'm building out **SportCache Analytics**, an ML prediction and anomaly detection layer on top of the live athletics API, as my final year project. I also do freelance full-stack work — most recently **Nexpace POS**, a full restaurant management system with real-time kitchen, dispatch, and rider apps.

---

## 🏃 What I'm Building

**[SportCache](https://sportcache.com)** — Sports data infrastructure for African athletics & cycling
- 🔴 Live results and timing ingestion (photo-finish, Lynx timing, TCP push)
- 📡 Public REST API (`api.sportcache.com`) — sport-namespaced, WA/UCI-standard formats
- 🎥 Broadcast overlay system (`broadcast.sportcache.com`) — Next.js + Supabase Realtime + GSAP
- 📊 Analytics & ML layer — FastAPI + scikit-learn on top of live meet data
